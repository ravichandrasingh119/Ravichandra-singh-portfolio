## Project Overview

This is a responsive personal portfolio website created for Web Design Assignment 1. It includes Home, About Me, Skills, Projects, and Contact sections with natural student-style content.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap CDN
- Responsive Web Design
- Flexbox and CSS Grid
- Hover effects and transitions

## Assignment Requirements Covered

- Headings and paragraphs
- Hyperlinks
- Profile image
- Lists
- Skills table
- Contact form
- External CSS file
- JavaScript form validation
- Responsive design for desktop and mobile
- Hover effects and simple transitions

## How To Run

Open `index.html` in any modern browser. Internet access is useful because Bootstrap is loaded through a CDN, but the custom CSS keeps the page readable even without it.
